## 改变与使用入口

新增根导出的 `McbeServer`，默认使用可靠调度并创建可协商的 `V2Bridge`。
它复用现有服务生命周期，不复制传输、等待表或分片实现。
通过 `server.v2` 注册能力与流，或发起协商后的请求和流式消费。
显式传入的设置除调度模式外均保留；原 `McbeServerFacade` 构造参数与旧默认行为不变。

主要改动：

- `src/mcbe_ws_sdk/server.py` 与根 `__init__.py`：新入口、必要的 v2 与流类型转出；旧服务模块清理过时说明。
- `examples/basic-server/server.py`：受管理钩子内直接等待原生命令，并通过公共接口订阅玩家消息。
- `examples/addon-server/server.py` 与 `capabilities.ts`：背包查询、自定义回声与元数据、流式完成和提前取消；删除宿主自行维护的请求任务。
- 双语迁移与扩展作者指南，以及 README、快速开始、架构、示例说明、附加包说明与 API 导航：同步新旧合同和未发布范围。

使用步骤见[迁移指南](../../../migration.zh.md)与[扩展作者指南](../../../extension-authors.zh.md)，不在验收记录重复维护。
