## 改变与入口

新增协商能力 `stream/1` 和 open／item／end／error／cancel 五种严格消息。
每项有独立逻辑序号，可复用 R11 多片传输；不预先计算整个流长度，不用固定发送间隔冒充背压。
Python `bridge.streams.register` 注册生产者，`bridge.stream`／`endpoint.stream` 消费异步迭代器。
TypeScript `registerV2Stream`／`endpoint.registerStream` 注册，`endpoint.stream` 消费。
完整字段、资源预算、生命周期和使用约定见[双语协议文档](../../../protocol-v2.zh.md)。

主要文件：Python `profiles/mcbews_v2/{streams,runtime,codec}.py`、`manifest.json`、`vectors.json`；
TS `bridge/v2/{streams,runtime,codec}.ts`、路由与能力上下文；生成器与生成资产。
流处理器与原子能力各自注册，普通请求、通知和不同流共享原有连接调度器。
