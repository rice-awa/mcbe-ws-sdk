## 边界

同步 CPU／阻塞日志处理器仍占用事件循环，宿主需自行移出，观察者需配合 asyncio 取消。
诊断通道为 best-effort；最近 wire ACK 缓存有界，淘汰／迟到后可能失去诊断上下文，
配对始终由独立请求表负责。直接操作公开 response_queue 不携带原操作上下文。
secret_keys 遮盖 JSON 对象键，字符串嵌套协议应配置 secrets 字面量；旧 RAW 回调保持未脱敏。
