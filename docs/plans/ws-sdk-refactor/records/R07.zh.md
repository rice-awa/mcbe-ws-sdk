## 实现

- 新增 NativeEventSubscriptions：按名称发送原生 subscribe/unsubscribe；重复注册
  独立令牌、观察/拦截共用引用计数、最后移除才退订。PlayerMessage 保留订阅不退订。
- ConnectionState.native_events 仅 reliable 模式可用；沿用有界观察/业务调度器、
  控制优先级发送器和连接关闭流程。注册数量与等待时间有界，发送不确定时关闭注册表。
- NativeEvent 保存完整原始结构，各观察者/拦截器独立副本。可选 NativeEventHook
  接收其他事件，PlayerMessage 保持类型化钩子。同玩家整链 FIFO，其他玩家并行。
- InterceptResult 明确 allow/reject/transform；异常或无效结果拒绝本次业务。
  观察者只通知、异常继续、返回值不影响业务；原始回复先配对，保留桥接分类先执行。
  变换不得改变事件名/玩家身份，也不能生成保留桥接前缀。
- 旧默认模式及回调顺序不变，ConnectionState 位置参数布局不变。未升级依赖、
  修改协议资产或实现 R08。仅 PlayerMessage 属既有已验证事件，其他名称不承诺游戏支持。
