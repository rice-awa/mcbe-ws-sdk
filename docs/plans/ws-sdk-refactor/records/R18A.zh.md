## 改动摘要

| 工作包 | 主要改动 |
| --- | --- |
| D01 回归与依赖 | `addon/package.json`、`package-lock.json`、两个 pack manifest 固定 `@minecraft/server 2.8.0`、`@minecraft/server-ui 2.1.0`、gametest `1.0.0-beta`、`min_engine_version [1,26,30]`；`manifest.test.ts` 断言真实产物值；`rollup` override 4.65.0 保证本地可构建 |
| D02 前缀与帮助 | `examples/addon-server/server.py` 与 `examples/basic-server/server.py` 只处理去空白后以 ASCII `!` 开头的消息；普通聊天、裸 `help`/`帮助`、句中 `!`、全角 `！` 静默；裸 `!` 给用法，未知 `!x` 给提示；帮助与错误文本按 UTF-8 字节边界截断 |
| D03 能力与错误 | `demoCapabilities.ts` 提供 `demo.echo`、`demo.ticks` 流和受限 `run_world_command`（`say` 允许列表 + 危险命令拒绝）；默认入口只注册两个只读能力；`main.demo.ts` 与 `--demo` 构建分离；远端错误映射为 `UNSUPPORTED_METHOD`/`INVALID_PARAMS`/`HANDLER_FAILED` 并保留有界消息；示例不向玩家展示请求 ID 或堆栈 |
| D04 生命周期诊断 | 默认 `--log-raw` 关闭；准入、拒绝、READY、会话失效与关闭原因有固定字段；EOF/断连只按证据归类 |
| D05 强制准入 | `McbeServer` 唯一入口；`WS_TRANSPORT_CONNECTED → NEGOTIATING → READY_V2 → CLOSING → CLOSED`，失败 `REJECTED → CLOSED`；READY 前丢弃业务帧并计数；拒绝时尽力发送 `mcbews:protocol_reject` 后以 1008 关闭；READY 前不产生业务 `CONNECTED`/`on_connected` |
| D06 删除 V1 | 删除 `profiles/mcbews_v1`、`extensions/mcbews_v1`、`addon/` Python 包、`McbeServerFacade`、`AddonBridge*`、旧 DTO/适配器、`V2Bridge(negotiate=...)` 与公开 `activate`；addon 删除 `protocol.ts`、`responseSync.ts`、`testing.ts`、`textResponse.ts`，路由只识别 `mcbews:negotiate_v2` 与 `mcbews:packet_v2`；旧路由记录拒绝日志 |
| D07 分发与文档 | 生成器只投影 V2 资产；`check_protocol_names.py`、`check_dist.py`、`probe_installed_contract.py` 改为 V2-only；CI/release 增加 demo 构建；双语文档、迁移指南、示例说明与导航按 V2-only 重写，删除旧协议/扩展页 |

旧符号、调用方与替代关系的完整清单见 [R18A-v1-inventory.zh.md](R18A-v1-inventory.zh.md)。
